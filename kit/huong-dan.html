Cài Inspiration Vault

Gửi ảnh, video ngắn hoặc link bạn thấy hay vào Claude. Claude phân tích, chống trùng, rồi lưu thành ghi chú trong kho riêng của bạn trên GitHub. Xem lại mọi ý tưởng trên một trang web, ngay trên điện thoại. Cài một lần, khoảng 15 phút.

Cần chuẩn bị

  • Tài khoản Claude gói trả phí (có tính năng kết nối GitHub và chạy tác vụ).
  • Tài khoản GitHub (miễn phí), tạo ở bước 1.
  • Hai file người gửi hướng dẫn này đưa cho bạn: inspo.zip và inspo-report.zip. Lưu vào điện thoại, không giải nén.

1Tạo kho trên GitHub

  1. Mở github.com bằng trình duyệt điện thoại, tạo tài khoản (hoặc đăng nhập).
  2. Bấm dấu + ở góc trên → New repository.
  3. Đặt tên inspiration-vault, chọn Private, tick Add a README file → Create repository.

Ghi lại: tên tài khoản GitHub của bạn và tên kho, dạng ten-ban/inspiration-vault. Bước 4 sẽ dùng.

2Cho Claude dùng GitHub

  1. Trong Claude, mở phần cài đặt Connectors (Kết nối), chọn GitHub → Connect, đăng nhập GitHub.
  2. Khi GitHub hỏi cho phép truy cập kho nào, chọn inspiration-vault.

Lưu ý: nếu không thấy mục này trong app, mở claude.ai bằng trình duyệt. Lần đầu dùng, Claude có thể hỏi lại quyền truy cập kho: chọn cho phép.

3Cài 2 skill

  1. Mở claude.ai bằng trình duyệt (dễ nhất trên máy tính, điện thoại cũng được).
  2. Vào cài đặt, mục Skills → tải skill lên → chọn inspo.zip.
  3. Làm lại với inspo-report.zip. Bật cả hai skill.

4Tạo Project "Inspiration"

  1. Trong Claude, vào Projects → tạo mới, đặt tên Inspiration.
  2. Mở phần hướng dẫn (instructions) của Project, dán đoạn dưới, sửa 2 chỗ trong ngoặc nhọn.
Hướng dẫn cho Project
Vault: <tên-github>/inspiration-vault
Tôi là <tên bạn>. Trả lời tiếng Việt, ngắn gọn.
Khi tôi gửi ảnh, video ngắn hoặc link để lưu: dùng skill inspo.
Khi tôi muốn xem các ý tưởng: dùng skill inspo-report.

5Dùng hằng ngày

Lưu một ý tưởng: trong Project Inspiration, mở đoạn chat mới, gửi ảnh chụp màn hình, video ngắn hoặc link, kèm một câu vì sao bạn lưu. Ví dụ:

Tin nhắn mẫu
Lưu cái này, mình muốn thử làm món này cuối tuần.

Lần đầu, Claude tự dựng kho (thư mục, danh mục) rồi mới lưu. Claude trả lời ngắn: nó là gì, có đáng không, nên làm gì tiếp. Bạn bàn thêm hoặc nói "lưu" là xong.

Xem tất cả: nhắn mở trang ý tưởng. Claude tạo một trang web riêng tư, lọc theo danh mục, có ảnh. Lưu hoặc ghim link đó để mở nhanh. Muốn cập nhật trang: nhắn cập nhật trang ý tưởng.

Danh mục: có sẵn Công việc, Nội dung, Học, Đời sống, Khác. Khi ý tưởng không vừa danh mục nào, Claude sẽ hỏi bạn có muốn thêm danh mục mới.

Mẹo: link Facebook, TikTok, Instagram thường cần đăng nhập nên Claude không đọc được. Gửi kèm ảnh chụp màn hình cho chắc.

+Tuỳ chọn: xem bằng Obsidian

Trang ý tưởng ở bước 5 là đủ để xem. Muốn đọc và sửa ghi chú như một cuốn sổ, cài Obsidian. Trên điện thoại hơi rườm rà; trên máy tính dễ hơn.

Tạo mã truy cập GitHub
  1. GitHub → ảnh đại diện → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Repository access: Only select repositories → inspiration-vault. Permissions → Contents: Read and write.
  3. Tạo, rồi sao chép mã (chỉ hiện một lần).
Cài Obsidian và kéo kho về
  1. Cài Obsidian từ App Store / Google Play, tạo một vault trống tên Inspiration (không bật iCloud nếu dùng cách này).
  2. Settings → Community plugins → bật → Browse → tìm Git → Install → Enable.
  3. Trong cài đặt plugin Git: điền Username là tên GitHub, Password/Token là mã vừa tạo.
  4. Mở bảng lệnh (vuốt xuống hoặc nút lệnh) → Git: Clone an existing remote repo → dán https://github.com/<tên-github>/inspiration-vault.git → thư mục để trống → đồng ý.
  5. Trong cài đặt plugin, đặt Auto pull interval khoảng 30 phút để ý tưởng mới tự về.

Gặp lỗi

  • Claude báo không vào được kho: làm lại bước 2, kiểm tra đã cho phép inspiration-vault, và dòng Vault: ở bước 4 đúng tên.
  • Claude không dùng skill: kiểm tra 2 skill đã bật (bước 3), và bạn đang chat trong Project Inspiration.
  • Link không đọc được: gửi ảnh chụp màn hình thay link.
