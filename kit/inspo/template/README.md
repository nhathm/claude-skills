# Inspiration

Ảnh, video ngắn, link bắt gặp khi lướt mạng. Claude phân tích trước khi lưu.

## Cách dùng
- Gửi ảnh / video ngắn / link vào một đoạn chat mới trong Project "Inspiration" của Claude, kèm 1 câu: vì sao lưu, định dùng vào đâu.
- Muốn xem tất cả ý tưởng: nói "mở trang ý tưởng" (skill `inspo-report`).

## Quy ước
- Note: `notes/INS-#### <tên ngắn>.md`; ảnh: `attachments/INS-####.<ext>`; video: chỉ lưu ảnh tóm tắt `attachments/INS-####.sheet.jpg`.
- `category`: nhóm theo mảng việc của chủ vault, xem `categories.md` (tự thêm được).
- `status`: raw · inbox · to-try · tried · archived
- `type`: skill · project · tool · design-pattern · idea · setup
- `effort`: 15-phut · 1-buoi · 1-tuan
- Chống trùng: cùng file, cùng link, hoặc ảnh gần như giống hệt.

Trên máy tính có Obsidian: mở `Inspiration.base` để xem dạng bảng.
